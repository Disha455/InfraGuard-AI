# core/utils

Pure utility functions with no framework dependencies.

Planned implementations:
- `image_utils.dart`     — image picking, format validation, size clamping
- `date_utils.dart`      — formatting of run-directory timestamps
                           (e.g. "run_20260802_125021" → "Aug 2, 2026 12:50")
- `file_utils.dart`      — path manipulation helpers for local artefact files
